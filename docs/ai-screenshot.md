# სქრინშოტიდან ტრანზაქციის მონახაზი

ეს პირადი შესაძლებლობა აქტიურდება მხოლოდ `AI_SCREENSHOT_USER_ID`-ში მითითებული დადასტურებული ანგარიშისთვის. ცვლადის არქონისას კონტროლი არ ჩანს და API უარყოფს მოთხოვნას. ტექსტით შევსება ამ შეზღუდვას არ ექვემდებარება.

ანგარიშის მისაბმელად გაუშვით `node --import tsx scripts/enable-ai-screenshot.ts <email>`. სკრიპტი ამოწმებს არსებულ დადასტურებულ ანგარიშს და ID-ს წერს მხოლოდ იგნორირებულ `.env.local` და `.local/screenshot-owner-id.txt` ფაილებში. ბაზა არ იცვლება. იგივე ID დაამატეთ Vercel-ის Production გარემოში `AI_SCREENSHOT_USER_ID` ცვლადად, შემდეგ გამოაქვეყნეთ ახალი deployment. ID კოდში ან `NEXT_PUBLIC_` ცვლადში არ ჩაწეროთ.

მომხმარებელი ირჩევს ერთ PNG/JPEG/WebP სურათს (მაქსიმუმ 5MB), ხედავს preview-ს და მხოლოდ „ამოკითხვა“-ზე დაჭერით გზავნის. ბრაუზერი სურათს ადგილობრივად ამცირებს მაქსიმუმ 2048px-მდე; გადაცემული JPEG მაქსიმუმ 3MB-ია, რათა მოთავსდეს ჰოსტინგის მოთხოვნის ლიმიტში. ძალიან გრძელი სქრინშოტი წინასწარ ამოჭერით. სერვერი ზღუდავს მოთხოვნის მოცულობას, სრულად დეკოდირებს სურათს, ამოწმებს რეალურ ფორმატს და შლის metadata-ს ხელახალი კოდირებით.

API `/api/ai/transaction-screenshot` ამოწმებს სესიას, ანგარიშის ID-ს, დადასტურებას, origin-სა და პორტფელის კუთვნილებას. ლიმიტია 3 მოთხოვნა წუთში და 20 მოთხოვნა 24-საათიან ფანჯარაში; არასწორი ამოკითხვის მცდელობებიც ითვლება. ავტომატური განმეორებითი ფასიანი მოთხოვნა არ კეთდება.

პროვაიდერი არის `gpt-6-luna`, იგივე სერვერული `OPENAI_API_KEY`-ით და Responses `store:false`-ით. ეს პროვაიდერის ყველა ტიპის შენახვის გამორთვას არ ნიშნავს. სურათი რჩება მხოლოდ მოთხოვნის მეხსიერებაში; ფაილის API, Blob, ბაზა ან ლოგი მის შესანახად არ გამოიყენება. პირადი მონაცემები გაგზავნამდე დაფარეთ.

AI აბრუნებს მხოლოდ ერთ მონახაზს. მრავალ ჩანაწერს, გაურკვეველ ციფრებს, არადასრულებულ ორდერს, არა-USD ფასსა და კრიპტოში გამოხატულ საკომისიოს მომხმარებელი ხელით აზუსტებს. USDT/USDC ავტომატურად USD-დ არ გადაიქცევა. არსებული ვალიდაცია და აქტივის არჩევა უცვლელია. „ფორმაში გადატანა“ ჩანაწერს არ ინახავს: საჭიროა ცვლილების შედეგის გადამოწმება და ცალკე „შენახვა“.

ტესტები იყენებს სინთეზურ სურათებსა და ყალბ პროვაიდერს; რეალური OpenAI მოთხოვნები და ლაივ ტრანზაქციები არ სრულდება.

სურათი შეიძლება ჩაისვას Ctrl+V-ით მხოლოდ ჩასმის არეზე ფოკუსისას. ამოკითხვა აბრუნებს სტატუსს, ვალუტას, შესრულებულ რაოდენობასა და ფასს. გაუქმებული შეუსრულებელი ორდერი ვერ გადადის ფორმაში; ნაწილობრივი შესრულება საჭიროებს ცალკე გადამოწმებას. ორდერის მოთხოვნილი რაოდენობა და ლიმიტის ფასი შესრულებულ ნაწილს არ ჩაანაცვლებს. USDT/USDC ინარჩუნებს ანგარიშსწორების ვალუტას; ისტორიული USD კურსი ხილული და რედაქტირებადია, საწყისად 1. უცხო/უცნობი ვალუტის ფასი ხელით ივსება USD-ში. საკომისიო უნდა იყოს ანგარიშსწორების ვალუტაში; სხვა ვალუტაში ამოკითხული საკომისიო ხელით დასაზუსტებელია. თარიღი სავალდებულოა. საკომისიო სურვილისამებრ ივსება: ცარიელი ველი 0-ად ჩაითვლება, შეყვანილი მნიშვნელობა კი ვალიდაციას გაივლის. საბოლოო ვალიდაცია სრულდება „მონახაზის დადასტურებაზე“; ფინანსური ჩანაწერი კვლავ მხოლოდ ძირითადი ფორმის ხელით შენახვისას იქმნება.
