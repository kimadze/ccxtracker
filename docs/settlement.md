# ანგარიშსწორება

ახალი ყიდვა/გაყიდვა საწყისად USDT-ს იყენებს. შესაძლებელია USD ან USDC. ერთეულის ფასი და საკომისიო არჩეულ ვალუტაში იწერება. სტეიბლკოინის ისტორიული USD კურსი ხილულია, რედაქტირებადია და ინახება ტრანზაქციასთან. სხვა ტიპები კვლავ USD თვითღირებულებას/საკომისიოს იყენებს.

ყიდვა ხარჯავს არჩეულ ნაშთს; USD-ზე ავტომატური გადართვა არ ხდება. გაყიდვა სტეიბლკოინის არსებულ პოზიციას ზრდის წმინდა შემოსავლით. ორივე მოქმედება ერთი ჩანაწერით ატომურად გადაითვლება. გაყიდვის შემოსავალი ახალი შენატანი არ არის.

მოხმარებული სტეიბლკოინის თვითღირებულება პროპორციულად მცირდება; მისი ისტორიული USD კურსის განსხვავება რეალიზებულ შედეგში აისახება. ახალი პოზიციის თვითღირებულება და გაყიდული პოზიციის P/L შენახული კურსით გამოითვლება. მიმდინარე შეფასება საბაზრო კურსს იყენებს; დაკარგული ფასი ჯამს არასრულად მონიშნავს. USD ნაშთი და სტეიბლკოინები მიმოხილვაში ცალკეა, საერთო ღირებულებაში თითოეული მხოლოდ ერთხელ ითვლება.

მიგრაცია `0018` ძველ ჩანაწერებს USD/1 ანგარიშსწორებით ავსებს და ამატებს USDT/USDC კატალოგის ჩანაწერებს. აუდიტი, აღდგენა და JSON ექსპორტი ორივე ველს ინარჩუნებს. ძველი აუდიტი ველების არქონისას კვლავ USD/1-ად იკითხება. პოზიციის ისტორია აჩვენებს იმ ტრანზაქციებსაც, სადაც ის ანგარიშსწორების მხარეა.
