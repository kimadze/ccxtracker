# ადმინისტრირება

`/admin` ხელმისაწვდომია მხოლოდ ავტორიზებული, დადასტურებული ანგარიშისთვის, რომლის ელფოსტა სერვერის `ADMIN_EMAILS` სიაშია. ცარიელი სია წვდომას არავის ანიჭებს. რამდენიმე მისამართი გამოიყოფა მძიმით. ცვლადი არ უნდა იყოს `NEXT_PUBLIC_`.

პანელი მოიცავს სისტემის მდგომარეობას, შეტყობინებების რიგებს, AI-ის ბოლო 24 საათის გამოყენებას/ლიმიტებს, მომხმარებლების საიტზე წვდომასა და ადმინისტრაციულ ისტორიას. API გასაღებები, Telegram chat ID, პორტფელის თანხები და შეტყობინებების ტექსტები პანელში არ გადაიცემა.

AI-ის საერთო გათიშვა ახალ ტექსტურ/სქრინშოტის მოთხოვნებს ბლოკავს; უკვე დაწყებული მოთხოვნა შეიძლება დასრულდეს. ორივე ფუნქცია საერთო მომხმარებლისა და გლობალურ 24-საათიან ლიმიტს იყენებს. ხარჯი აღირიცხება ამ ცვლილებიდან მიღებული usage ტოკენებით: Luna input $0.10/M, cached input $0.01/M, output $0.50/M. უცნობი ტოკენები/ხარჯი რჩება უცნობად და ჯამში არ შედის; ეს არ არის პროვაიდერის საბოლოო ანგარიში. შეყვანილი ტექსტი და სურათი usage ცხრილში არ ინახება.

შეჩერება აუქმებს მომხმარებლის სესიებს და საიტზე წვდომას; ფინანსური ისტორია შენარჩუნდება. აღდგენის შემდეგ მომხმარებელი თავიდან შედის. ადმინისტრატორის შეჩერება პანელიდან აკრძალულია. ეს მოქმედება Telegram-ის პირად შეტყობინებებზე მომხმარებლის არჩევანს არ ცვლის.

შეტყობინების ხელახალი ცდა მხოლოდ რიგში აბრუნებს წარუმატებელ, შეუგზავნელ და ექვს საათზე ახალ ჩანაწერს. საბოლოო თანხმობასა და ჩანაწერის ვარგისიანობას არსებული მიწოდების პროცესორი გადაამოწმებს. უკვე გაგზავნილი, გაუქმებული ან BOT_BLOCKED ჩანაწერის ცდა დაუშვებელია. Telegram-ის დაკარგული პასუხის შემთხვევაში დუბლირებული მიწოდება ვერ გამოირიცხება და მოქმედებამდე ჩანს გაფრთხილება.

გამოქვეყნებამდე გამოიყენება დამატებითი `0019` მიგრაცია. არსებული ფინანსური ცხრილები არ იცვლება. სამუშაო გარემოსა და Production-ზე `ADMIN_EMAILS` უნდა განისაზღვროს; გარემოს ცვლილების შემდეგ საჭიროა ახალი deployment.
